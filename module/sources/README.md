# Sumber Modul

Direktori ini memuat berkas pendukung tiap bab: skrip, potongan kode, dan
templat yang dirujuk dari naskah modul.

Susunannya satu subdirektori per bab, dari `chapter01` sampai `chapter14`.
Naskah bab merujuk berkas di sini dengan penulisan seperti
`sources/chapter02/ukur-koneksi.sh`, sehingga mahasiswa dapat menjalankan
perintah yang sama tanpa menyalin ulang dari halaman cetak.
